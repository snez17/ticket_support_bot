## Стартовые алерты

| Событие | Действие |
|---------|----------|
| Latency > 1 с | Алерт → смотреть нагрузку |
| Error rate > 5% | Алерт → fallback режим |
| Queue > 5000 | Алерт → добавить мощности |
| Reopen Rate > 12% | Алерт → проверить качество |
| CSAT < 4.0 | Алерт → анализ ответов |

---

## Деградация модели vs Изменение потока

| Симптом | Деградация | Изменение потока |
|---------|------------|------------------|
| Падает точность | Только на старых категориях | На всех категориях |
| Меняются топики | Нет | Да |
| Confidence падает | Да | Нет (или наоборот) |
| Решение | Переобучить модель | Обновить базу знаний |
